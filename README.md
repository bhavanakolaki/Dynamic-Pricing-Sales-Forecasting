# Dynamic Pricing and Sales Forecasting System

## Project Overview
This project is an AI-powered Dynamic Pricing and Sales Forecasting application that predicts future sales and recommends optimal product prices using Machine Learning algorithms.

## Features
- Sales prediction using ML models
- Dynamic price recommendations
- User authentication system
- Interactive dashboard
- Data-driven business insights

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML, CSS, JavaScript
- SQLite

## Installation

Clone the repository:
git clone <repository-url>

Create virtual environment:
python -m venv venv

Activate virtual environment:
venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt

Run the application:
python app.py

Open browser:
http://127.0.0.1:5000/dashboard
